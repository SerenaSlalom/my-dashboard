# FastForward Logistics — Ops Dashboard

An internal operations dashboard for FastForward Logistics, a mid-size freight and
supply chain company. Built as a Protogen Academy capstone project.

See [BRIEF.md](BRIEF.md) for the full project brief, target audience, and grading
requirements. Visual design follows the **Aether** design system in
[design/aether](design/aether).

## Stack

- Vue 3 + TypeScript
- Vite
- Vue Router
- Chart.js (via vue-chartjs)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
